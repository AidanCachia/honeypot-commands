# LLM Honeypot Log Files and Output

This file documents the commands used to inspect the log files and output folders created by the LLM-based honeypot. These files were used to review honeypot activity, runtime output, and structured JSONL session logs.

## 1. Listing LLM Honeypot Output Files

The following command was used to show the files and folders inside the LLM honeypot project directory, including log files and output folders:

```bash
ls -lh
```

## 2. Inspecting the Main SSH Honeypot Log

The following commands were used to inspect the main SSH honeypot log file:

```bash
cat ssh_honeypot.log
```

```bash
less ssh_honeypot.log
```

```bash
tail -f ssh_honeypot.log
```

```bash
tail -n 50 ssh_honeypot.log
```

## 3. Inspecting Additional Log Files

The following command was used to list log files in the main LLM honeypot folder:

```bash
ls -lh *.log
```

The following commands were used to inspect additional log files:

```bash
less llm_usage_attacker3.log
```

```bash
less attack_usage.log
```

```bash
tail -n 100 attack_usage.log
```

## 4. Inspecting Structured JSONL Logs

The following command was used to list the structured JSONL log files inside the `logs` folder:

```bash
ls -lh logs
```

The following command was used to inspect a specific JSONL log file:

```bash
tail -n 50 logs/20260423_133921.jsonl
```

## 5. Checking the Logs Folder

The following command was used to enter the `logs` folder:

```bash
cd logs/
```

The following command was used to list the JSONL log files stored inside the folder:

```bash
ls
```

## 6. Checking the Dataset Folder

The following command was used to enter the dataset folder:

```bash
cd dataset
```

The following command was used to list the dataset folder contents:

```bash
ls
```

## 7. Dataset Files

The dataset folder contained project data files such as:

```text
attack_patterns.json
corrections.json
filesystem.json
llm_usage_attacker5.log
```

## 8. Purpose of Log Inspection

These commands were used to inspect runtime logs, attack/session output, and structured JSONL records generated by the LLM-based honeypot. This helped review the honeypot interaction evidence separately from CPU and RAM resource monitoring.
